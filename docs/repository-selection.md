## Semantic architecture boundary

Repository/public-surface priority is not semantic containment.

```text
THIA = total-system relation
D-ND = logical/cognitive kernel and deeper research source
THIAMAN = manager / architect function
Multi_Agent_OS = distributed presentation / execution surface
MAIOS = current project-centred operational/public convergence
```

A reviewer may encounter MAIOS before THIA because the portfolio leads from the
current usable result. This does not make THIA a component of MAIOS.

## Selection criterion

A repository belongs in the main review path when a reviewer can see:

- what it does;
- why it matters now;
- what is inspectable;
- current maturity level;
- how it relates to the current system without being falsely absorbed by it.

A surface belongs in the main path when it shows behavior a repository alone
cannot show:

- current setup or operating interaction;
- live state;
- public/private lens separation;
- Lab cycle state;
- dashboard evidence;
- operational continuity;
- transfer from context/intent into a reviewable workflow.

## Boundary

The THIA implementation repository is private.

THIA itself is not correctly described as a private repository or merely a
runtime/coordination layer. It is the total-system relation and can be explained
publicly through curated architecture, public surfaces and review-safe evidence
without exposing private implementation detail.
