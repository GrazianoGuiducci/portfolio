# Curation Matrix

This matrix tracks which source artifacts can become portfolio material. Source
files may live in private or working repositories; the public form is always a
curated, review-safe document in this portfolio.

Current curation rule:

```text
current operational relevance
-> inspectable evidence
-> reusable component / competence
-> deeper source
-> historical lineage
```

Public review order does not redefine semantic ownership: THIA remains the
total-system relation while MAIOS is the current project-centred
operational/public convergence.
