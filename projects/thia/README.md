# THIA

## Summary

**THIA is the total-system relation / whole ecosystem context.**

It should not be reduced to a coordination/runtime layer, even though concrete
THIA incarnations include coordination, runtime, public sites, repositories,
Labs, agents, assistants, memory, routing, services, bridges, public/private
surfaces and distributed nodes.

The implementation repository is private. THIA as a system has public surfaces
and can be described through curated, review-safe architecture and observable
behavior.

Public surfaces:

- https://d-nd.com
- https://d-nd.com/thia
- https://d-nd.com/ai-lab

## Portfolio role

THIA provides the whole-system frame in which relations among intent, systems,
interfaces, nodes, memory, research, execution and public/private surfaces can
be understood.

Concrete incarnations represented in the THIA repository have included:

- distributed nodes and hosts;
- agent and model routing;
- public sites and APIs;
- Siteman and publication functions;
- memory and working-state surfaces;
- research/Lab connections;
- services, bridges and execution paths;
- public/private separation and operator gates.

These are **incarnations/functions of THIA**, not an exhaustive definition of
THIA itself.

## Why older descriptions can differ

Historical THIA architecture documents were often written from the viewpoint
of the implementation that existed at that moment. They may describe THIA as a
runtime, neural kernel, distributed intelligence, container/service system or
coordination architecture.

For this portfolio, those documents are implementation evidence. The selected
current semantic relation is broader:

> THIA = total system.

Do not let an implementation view silently replace the owner/operator-level
identity.

## Operational awareness boundary

In this portfolio, “awareness” is operational/system awareness: relevant
context, state, sources, evidence, limits, uncertainty, failures and memory can
be reconstructed or exposed in a way that changes action.

This is not a claim of consciousness or subjective experience.

## What it shows

At different incarnations and maturity levels, THIA provides evidence for:

- distributed-system continuity across nodes and surfaces;
- relationships among public and private operating contexts;
- memory and state preservation for long-running work;
- routing and orchestration among agents, tools, services and interfaces;
- integration of research, execution and publication surfaces;
- explicit operator, review and effect boundaries;
- the ability to preserve a whole-system relation while individual components
  evolve.
